Sourcing, all entries

    The route from an edit to the site

      The public site never talks to Sanity. It reads the snapshot only, so pages stay small, the site stays up if Sanity is down, and every content change is kept in git history.

      Changing or adding an entry

      A. Open the Studio

      B. Edit

      1. The left column lists the kinds of entry: Movement, Event, Person, Organization, Text, Place. Click one.
      2. The next column lists the entries of that kind. Click one to change it. To add one, click the create button at the top of that column (a pencil or plus icon).
      3. Fill in or change the fields. For a link to another entry, go to Relationships, click Add item, type the relationship type (for example led_by) and pick the target entry. For a citation, go to Sources, click Add item and fill in the citation, its type and its URL.
      4. Sanity saves as you type. At this point the entry is a draft, and drafts are private.
      5. When the entry is ready to be read by anyone, do two things: turn on the Published switch near the bottom of the form, and click the Publish button at the bottom of the screen. The button moves the entry out of draft. The switch tells the sync robot to put it on the site.

      C. Send it to the site

        If you stop after step 5, the nightly run at 02:00 India time does the rest. Button labels in the Studio can differ slightly between Sanity versions.

        Taking an entry off the site

        Turn the Published switch off, click Publish, and run the sync. The entry leaves the site. It stays readable through Sanity's API until you also choose Unpublish from the menu beside the Publish button.

        Is the Sanity data public?

        Yes. The dataset is public, and on Sanity's free plan it has to be. Private datasets need the paid Growth plan.

        • Anything you Publish in Sanity can be read through Sanity's API by anyone who knows the project id. The archive's own Published switch keeps an entry off this website. It does not hide it in Sanity.
        • Drafts are private. An entry you have typed but not clicked Publish on cannot be read from outside.

        What is better now: keep it public and free, and treat the Publish button as "the world can read this". Unfinished entries stay drafts.

        When to pay for private: once the dataset holds things that must not be read early, such as machine-suggested text from books, reviewer comments or contributors' personal details. Nothing on this site would change, because it never talks to Sanity.
